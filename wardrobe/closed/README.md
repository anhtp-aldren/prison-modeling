# Closed wardrobe

`wardrobe_closed.blend` is the closed-door variant of the `../wardrobe-views.png` reference. It uses dark steel with subtle gray scuffs, without red rust patches. The front has a solid backing and no interior props. Both doors retain editable hinge pivots.

The five `preview*.png` files show the model from three-quarter, front, back, side, and top angles. Run `../build_wardrobe.py -- --closed` through Blender 5.x to rebuild it; the exact PowerShell command is in `../README.md`.
